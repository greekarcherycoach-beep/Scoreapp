# Archery Lab – Score App (APK)

Η εφαρμογή σκοραρίσματος τοξοβολίας ως εφαρμογή Android. Το APK φτιάχνεται αυτόματα από το GitHub, χωρίς να χρειάζεσαι Android Studio.

## Βήματα

1. Φτιάξε νέο αποθετήριο στο GitHub (π.χ. `archery-lab-score`).
2. Ανέβασε **όλο το περιεχόμενο αυτού του φακέλου** (συμπεριλαμβανομένου του κρυφού φακέλου `.github`).
   - Με drag & drop στη σελίδα του αποθετηρίου («Add file → Upload files»), ή με git: `git add . && git commit -m "first" && git push`.
3. Πήγαινε στην καρτέλα **Actions → Build APK → Run workflow**. (Ξεκινά και αυτόματα με κάθε push στο `main`.)
4. Μετά από περίπου 5–10 λεπτά άνοιξε την ολοκληρωμένη εκτέλεση και κατέβασε από το **Artifacts** το `ArcheryLab-Score-APK` (zip). Μέσα είναι το `app-debug.apk`.
5. Αντίγραψε το APK στην ταμπλέτα και στα κινητά και εγκατέστησέ το. Αν ζητηθεί, επίτρεψε την «εγκατάσταση από άγνωστες πηγές».

## Δομή

| Αρχείο | Ρόλος |
|---|---|
| `www/index.html` | Η εφαρμογή (όλος ο κώδικας) |
| `capacitor.config.json` | Όνομα εφαρμογής και αναγνωριστικό (`gr.archerylab.scoreapp`) |
| `package.json` | Εξαρτήσεις (Capacitor και πρόσθετα) |
| `scripts/patch-android.js` | Προσθέτει δικαίωμα κάμερας, ελάχιστο Android 6 (SDK 23) και το εικονίδιο |
| `icons/` | Εικονίδια εφαρμογής |
| `.github/workflows/build-apk.yml` | Η αυτόματη κατασκευή του APK |

## Τι διαφέρει στην εφαρμογή Android

- **Σάρωση QR:** χρησιμοποιεί τον σαρωτή του Google ML Kit. Την πρώτη φορά μπορεί να κατεβάσει μια μικρή λειτουργία από τις Υπηρεσίες Google Play (χρειάζεται internet μία φορά, μετά δουλεύει χωρίς). Αν δεν λειτουργήσει, μπορείς να επικολλήσεις τον κωδικό χειροκίνητα.
- **Αποθήκευση και εξαγωγή:** ανοίγει το μενού κοινοποίησης του Android, για να αποθηκεύσεις το αρχείο στο Drive, στα Αρχεία ή να το στείλεις με μήνυμα. Η «Εκτύπωση / PDF» δημιουργεί αρχείο `apotelesmata.html` που ανοίγεις σε browser και εκτυπώνεις ή αποθηκεύεις ως PDF.
- **Φόρτωση αρχείου:** δουλεύει κανονικά από τον επιλογέα αρχείων.
- **Πλήρης οθόνη (⛶):** κρύβει τη γραμμή κατάστασης. Η οθόνη μένει αναμμένη όσο η εφαρμογή είναι ανοιχτή.

## Αν δεν συνδέονται οι συσκευές με QR

Η σύνδεση γίνεται απευθείας μεταξύ των συσκευών στο ίδιο Wi-Fi ή hotspot. Αν κάποιο δίκτυο μπλοκάρει την επικοινωνία μεταξύ συσκευών, χρησιμοποίησε το hotspot της ταμπλέτας ή άλλο router. Σε περίπτωση που δεν γίνεται σύνδεση, μπορείς να στείλεις τα σκορ με αρχείο (Αποθήκευση στο κινητό, Φόρτωση στην ταμπλέτα).

## Ενημέρωση της εφαρμογής

Άλλαξε το `www/index.html`, κάνε push και κατέβασε το νέο APK από το Actions. Η εγκατάσταση πάνω από την παλιά διατηρεί τα δεδομένα.

## Σημείωση

Το APK είναι «debug» και υπογράφεται με προσωρινό κλειδί. Είναι κατάλληλο για δική σου χρήση. Για δημοσίευση στο Play Store χρειάζεται υπογεγραμμένο release APK.
